# Student Marks Management System

A console-based Java application for managing student records, marks, grades, and rankings.

## Features

- Add student records
- Store marks for English, Mathematics, and Physics
- Calculate total marks
- Calculate average marks
- Generate grades automatically
- Search students by name
- Display student rankings
- Input validation for names and marks

## Concepts Used

- Java Fundamentals
- Methods
- Arrays
- 2D Arrays
- Loops
- Switch Statements
- Input Validation
- Searching
- Sorting (Bubble Sort)
